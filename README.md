# ff-gui PR evidence

Screenshots referenced from pull requests in the **private** `TheFeedFactory/ff-gui` repository.

They live here only because GitHub cannot render an image in a private repo's PR body: a
`raw.githubusercontent.com` URL on a private repo returns 404 to the reader's browser, and the
only alternative — GitHub's `user-attachments` CDN — is reachable only by dragging a file into
the web UI, not from CI or the CLI.

Everything here comes from a disposable dev box seeded with a **scrubbed** subset of staging:
every user identity in it is a generated `@ff-box.local` address, and no credential, token or
real person's details appear in any image.

Delete this repository to un-publish the images; the PRs that link them will simply show broken
images again.
